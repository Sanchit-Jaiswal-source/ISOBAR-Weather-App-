# Isobar Weather

A polished, responsive weather dashboard with live city search, current conditions, and a five-day forecast. Weather data is provided by [Open-Meteo](https://open-meteo.com/); no API key, server, or package installation is required.

## Run locally

Open `index.html` in a modern browser. An internet connection is needed for live city search and weather data. If a weather request fails, the page displays clearly labeled sample fallback conditions.

## Publish with GitHub Pages

1. Create a GitHub repository and upload `index.html` and this `README.md` (you can also upload `PRODUCT.md` and `DESIGN.md` if you want to keep the project notes with the source).
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)`, then save.
5. After GitHub Pages deploys the site, open the URL shown in the repository's **Settings → Pages**. For this repository, the expected address is:

   <https://sanchit-jaiswal-source.github.io/ISOBAR-Weather-App-/>

Add the deployed URL to the repository's **About → Website** field.
